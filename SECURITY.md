# Security policy

## Supported version

Security fixes are applied to the latest version on `main`.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature when available. If it is unavailable, contact the repository owner through the LinkedIn link on the GitHub profile. Do not include secrets, personal information, proprietary data, or exploit details in a public issue.

This repository uses synthetic data and is not validated or approved for regulated production use. A response or code change does not constitute a compliance certification.
