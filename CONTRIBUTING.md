# Contributing

Thanks for helping improve this portfolio project.

1. Open an issue describing the problem or proposed change.
2. Create a focused branch from `main`.
3. Follow the setup and verification commands in the README.
4. Add or update pytest and dbt checks for behavioral or data-model changes.
5. Open a pull request explaining the data impact, lineage implications, and verification performed.

Never contribute proprietary, personal, employer, manufacturing, production, or regulated data. Use synthetic examples only. Report security vulnerabilities according to `SECURITY.md` rather than through a public issue.
